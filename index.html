qbee-agent — local privilege escalation & arbitrary file tampering via symlink following

CVE-2026-65016 High · 7.7

n8n — SSO instance-role provisioning privilege escalation to instance owner

›

n8n's Enterprise SSO fails to block assignment of the global:owner role through instance-role provisioning. With N8N_SSO_SCOPES_PROVISION_INSTANCE_ROLE enabled, an SSO user whose IdP-supplied instance-role claim maps to global:owner gains full instance-owner access — a capability explicitly blocked on the token-exchange path.

CVE-2026-65981 High · 7.1

coturn — MOBILITY-TICKET session-resume authorization bypass

›

On the ICE-mobility session-resume path, credential adoption is skipped when the attacker's session is already authenticated, so ownership of the victim's allocation is never re-validated — enabling cross-user takeover of an active TURN allocation. Found via an auth-layer ↔ handler asymmetry in the STUN attribute view, then confirmed dynamically.

CVE-2026-55828 Medium · 6.0

qbee transport — symlink-chain path traversal in tar extraction

›

The go.qbee.io/transport tar-extraction routine validates paths lexically but follows symlinks created during extraction, letting an attacker write a file one level above the destination. Reached through qbee-agent running as root, it yields unauthorized root-level file writes outside the target directory. (CWE-22 / CWE-59)
